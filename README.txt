FILES

- styles.css
- app.js
- images/nauman-profile.jpg
- images/nauman-logo.svg
- files/Nauman-CV.pdf

GITHUB PAGES UPLOAD
1. Open your existing GitHub repository.
2. Replace the old index.html with this index.html.
3. Upload styles.css and app.js to the repository root (same level as index.html).
4. Open the images folder and upload nauman-profile.jpg and nauman-logo.svg.
5. Create a folder named files if it does not exist; upload Nauman-CV.pdf inside it.
6. Keep any existing project images/assets if they are still used elsewhere.
7. Commit changes and wait for GitHub Pages to publish.

IMPORTANT
- This is a redesigned portfolio starter. Check the Ayesha Beauty Hub project URL in index.html and replace it if your actual store URL is different.
- The WhatsApp form opens a pre-filled WhatsApp message; it does not save submissions on a server.
- Chatbot, n8n and AI projects are labelled as concepts/workflow builds where a public demo has not been confirmed. Change labels only when you have a real working demo.
- No date of birth or marital status is included.
- The CV is rewritten in a professional layout from the details supplied in your CV image. Verify every employer/date/title before sending it to employers; dates were not visible in the supplied CV.
